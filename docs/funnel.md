# Content Funnel — Jun Yuh Ad (saved reference)

Source: Instagram ad by Jun Yuh. Four-slide breakdown of a creator content
system organized by cadence (1x day / 1x week / 1x month) across four stages.

## 1. Create
| Cadence  | Action                  |
|----------|-------------------------|
| 1x day   | Post                    |
| 1x week  | Batch film              |
| 1x month | Update content pillars  |

## 2. Engage
| Cadence  | Action              |
|----------|---------------------|
| 1x day   | 300 comment replies |
| 1x week  | LIVE Q&A            |
| 1x month | Community challenge  |

## 3. Analyze
| Cadence  | Action                   |
|----------|--------------------------|
| 1x day   | Skip rate & views        |
| 1x week  | Identify 3 top performers |
| 1x month | Full content audit       |

## 4. Consume
| Cadence  | Action           |
|----------|------------------|
| 1x day   | 10 min scrolling |
| 1x week  | Save 5 videos    |
| 1x month | Try 3 new formats |
